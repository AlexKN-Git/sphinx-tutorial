
# 1. Чем Sphinx отличается от LaTeX

```{note}
Этот раздел — краткая теория. Достаточно прочитать один раз.
```

LaTeX — это язык разметки и система вёрстки, заточенная в первую очередь
под PDF. Sphinx — генератор документации, заточенный под HTML-сайт.

## Сравнение

| Что | LaTeX | Sphinx |
|---|---|---|
| Основной формат | PDF | HTML |
| Разметка | LaTeX | reStructuredText / Markdown |
| Ссылки | `\ref{}`, `\label{}` | `{ref}`, `{doc}` |
| Код | `listings` / `minted` | `{code-block}` |
| Поиск по документации | нет | есть |
| Совместная работа | сложно | удобно (Git + PR) |
| Расширяемость | пакеты | расширения Python |

## Аналогия

- LaTeX — «Word для математиков».
- Sphinx — «Википедия + Git + сборка PDF» для технической документации.
